# Overview presentation

User-selected direction: MISA reference dashboards, compact white panels with small corner radii, vivid gradient metrics and distinct categorical chart colors. Preserve current data and interactions.

Evidence: business, HR, retail and finance panels use different large radii and shadows. Shared chart palette uses five similar blue tints.

Implementation: shared scoped panel/KPI styles, distinct teal/blue/gold/coral/purple chart series. Preserve empty and unavailable states; do not synthesize data.
